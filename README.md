# JeevanSync AI

## AI-Powered Early Clinical Deterioration Prediction System

An end-to-end machine learning system for predicting clinical deterioration in ICU patients using time-series vital signs, lab results, and EMR data. The system predicts the onset of Sepsis, Shock, or qSOFA ≥ 2 within a configurable 6–12 hour prediction horizon.

---

## Architecture

The system follows a 9-layer production architecture:

```
┌─────────────────────────────────────────────────────────────────┐
│  Layer 1: Data Ingestion    (FastAPI + Redpanda/Kafka)          │
│  Layer 2: Preprocessing     (Sliding Windows + Feature Eng.)    │
│  Layer 3: Storage           (Data Lake + PostgreSQL + Redis)    │
│  Layer 4: Modeling          (XGBoost + BiLSTM + Transformer)    │
│  Layer 5: Explainability    (SHAP Local + Global)               │
│  Layer 6: Model Serving     (FastAPI + Docker + K8s)            │
│  Layer 7: Dashboard         (Streamlit Clinician UI)            │
│  Layer 8: Operations        (Prometheus + Grafana + CI/CD)      │
└─────────────────────────────────────────────────────────────────┘
```

## Dataset

| File | Records | Description |
|------|---------|-------------|
| `patients.csv` | 10,000 | Static demographics + deterioration labels |
| `vitals_timeseries.csv` | 417,867 | Hourly vital signs (HR, RR, SpO2, Temp, BP) |
| `labs_timeseries.csv` | 417,867 | Hourly labs (WBC, Lactate, Creatinine, CRP) |
| `hospital_deterioration_hourly_panel.csv` | 417,867 | Full joined panel |
| `hospital_deterioration_ml_ready.csv` | 417,867 | ML-ready features + target |

**Target:** `deterioration_next_12h` — binary label predicting clinical deterioration within 12 hours.

## Quick Start

### 1. Setup

```bash
# Create virtual environment
python -m venv venv
venv\Scripts\activate      # Windows
# source venv/bin/activate  # Linux/Mac

# Install dependencies
pip install -r requirements.txt
```

### 2. Run Preprocessing Pipeline

```bash
python -m src.preprocessing.pipeline --window-size 12 --mode engineered
```

### 3. Start Ingest API

```bash
python -m src.ingestion.ingest_api
# API available at http://localhost:8000
# Docs at http://localhost:8000/docs
```

### 4. Simulate ICU Data Stream

```bash
python -m src.ingestion.simulate_stream --mode direct --patients 100
```

### 5. Run Tests

```bash
pytest tests/ -v
```

## Feature Engineering

The preprocessing pipeline extracts **100+ engineered features** per observation:

| Category | Features | Examples |
|----------|----------|---------|
| Statistical | 8 per signal | Mean, std, min, max, median, skew, kurtosis, IQR |
| Trend | 4 per signal | Linear slope, delta, rate of change, acceleration |
| Variability | 15 total | HRV (SDNN, RMSSD), BPV, SpO2 variability |
| Clinical Scores | 10 total | MAP, Shock Index, qSOFA proxy, lactate alerts |
